AdMention AI

Track every advertiser mention, automatically. Paste a YouTube URL, search an advertiser, and jump to the exact second it was said.

Live showcase · full analyzer runs locally during development

What a user gets

  1. Paste a YouTube video URL and pull the show title, channel, and transcript.
  2. Search an advertiser such as Feldman Automotive, including aliases like Feldman.
  3. See every real mention with surrounding context, confidence, and timestamp.
  4. One click opens YouTube at that second — no scrubbing a long live show.

How it works

YouTube URL Video metadata Timestamped transcript Advertiser match Context + watch link

Stack

React, TypeScript, Vite, Tailwind, FastAPI, SQLAlchemy, SQLite/PostgreSQL, yt-dlp captions.

Status

Phases 1–8 are complete: URL analysis, transcripts, advertisers, mention search, context, and timestamp links. This public page is the portfolio face of the project.
